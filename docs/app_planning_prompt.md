# 🤖 App Factory 기획용 AI 프롬프트 (Prompt Template)

## 🛠️ App Factory Boilerplate 보유 기능 (참고용)
내가 가진 뼈대는 다음과 같은 모듈을 이미 완성된 형태로 보유하고 있어. 이 기능들은 추가 개발 없이 스위치(Config)만 켜면 즉시 사용할 수 있으니 기획 시 적극적으로 재사용해 줘.
- `ui_module`: 공통 색상, 버튼, 다이얼로그 등 디자인 시스템
- `auth_module`: 구글, 카카오, 네이버, 애플 소셜 로그인 및 회원 탈퇴 기능
- `monetization_module`: 구글 애드몹 (배너, 전면, 보상형, 네이티브 광고)
- `permission_module`: 카메라, 사진, 알림, iOS 추적 권한(ATT) 자동 팝업
- `settings_module`: 다크모드, 다국어 설정, 이용약관, 푸시 알림 토글
- `contact_module`: 개발자 문의, 앱스토어 별점 남기기, 앱 공유하기
- `notice_module`: 공지사항 및 강제 업데이트 팝업
